Connect Guildkeep to Supabase

Add the Supabase project URL and publishable key as Vite environment variables, then rebuild the app.

VITE_SUPABASE_URL VITE_SUPABASE_ANON_KEY

These are public client settings. Never put a Supabase secret or service-role key in this app.
